HOD MILITARY REWORK — DESIGN PROPOSAL (2026-10-10)
==================================================
Option B: a custom Star Wars military, structured like Old World Blues (workshop 2265420196). Nothing below is built
yet; this is the plan to agree on first.

CURRENT STATE
  ~95% vanilla WWII: 125/132 unit types, 308/321 equipment, 535/612 techs. HoD additions: 7 droid/clone units,
  13 equipment lines, 3 tech files (cis_droid_military, republic_military, special_forces_doctrine).
  descriptor.mod already replaces common/units and common/units/equipment; common/technologies is NOT replaced
  (vanilla tech files still load where the mod has no copy) — the rework adds replace_path for technologies and
  doctrines, like OWB.

WHAT WE TAKE FROM OWB
  1. Replace every WWII line; few equipment lines, named by role: inf_, veh_, wlk_, air_, ship_, sup_.
  2. Branching tiers instead of +5% ladders: a line forks at tier 2-3 (e.g. blaster vs slugthrower vs ion).
  3. Hidden ACCESS techs (can't be researched, granted by focus / event / starting history) gate faction and
     species content: clone production, droid foundries, beskar, Force users, Wookiee warriors...
  4. TECH LEVELS per domain gate tiers: a Rim backwater and a Core power feel different.
  5. Vehicles and warships through the designers (custom upgrades / modules); warships as hull SIZE classes.
  6. HQ unit per army type (works with the new deployed-HQ / capture / duel system).

WHAT A REPLACEMENT TOUCHES (beyond units / equipment / techs)
  history/units (every country's starting OOB and templates), common/ai_templates, common/ai_equipment,
  starting techs in history/countries, focuses / events / ideas that grant vanilla techs or equipment,
  production lines, unit icons and names (common/units/names*), localisation. This is the bulk of the work.

SUGGESTED PHASES (each one playable and tested before the next)
  1. Land core: tech levels + access techs, infantry / clone / droid / speeder / armour / support / HQ lines,
     land techs, starting OOBs + AI templates for the main factions (REP, CIS) first, then the rest.
  2. Space navy + air: hull classes, modules, fighters / bombers / gunships, their techs, starting fleets.
  3. Doctrines, species and elite units, Force strike teams (tie in with duels).
  4. Industry tree retheme, balancing pass, icons and loc polish.

DECISIONS (HoD, 2026-10-10)
  - Tech levels are ERAS, per domain: Pre-war -> Clone Wars -> Late war -> Imperial.
  - Infantry weapons branch by ROLE at higher tiers: standard rifles / heavy (repeaters, launchers: soft attack)
    / precision (long-range marksmen: breakthrough). Blaster vs slugthrower vs ion is flavour, not a branch.
  - Phase 1 = land core for REP + CIS first. Other countries keep working through a generic fallback (their
    current templates mapped onto the new generic trooper / speeder / armour lines), then get converted.

STILL OPEN
  - Which factions get which access techs at start (Kamino clones: REP; droid foundries: CIS + corporate
    members; beskar: Mandalore; species: their homeworlds)? Proposed as listed; confirm when phase 1 starts.

PHASE 1 SPEC — LAND CORE (REP + CIS)
=====================================
Starting point (audit): REP/CIS start with division templates only (Clone Legion = 9 vanilla infantry, CIS Droid
Battalion = 13 vanilla infantry, garrisons = 2 motorized, commandos = marines + engineer); the mod's clone/droid
sub-units are not used. Fleets are vanilla WWII ships (phase 2). Starting techs are mostly WWII.

ERAS (tech_levels.txt; researchable, expensive; the Clone Wars era is also granted by the war-start event)
  per domain: infantry, vehicles, support
  era_prewar (both start here) -> era_clone_wars -> era_late_war -> era_imperial
  each era unlocks the next tier of every line in its domain

  vanilla land units stay in place but rethemed in localisation (infantry -> Troopers, motorized -> Speeder

  Star Wars; they get converted country by country after phase 1 is tested.

ROUGH SIZE: ~25 equipment entries, ~12 sub-units, ~60 techs, 2 OOBs, AI templates, localisation + unit icons.
